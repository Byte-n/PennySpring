# 数据持久化存储规范

本文档定义 PennySpring 的存储归属与账本切换行为，适用于业务表、文件、AI 会话与设置、提供商配置和凭据。

## 决策

- 保留混合账本模式：本地账本与多台服务器的网络账本可以同时存在。
- 采用全量入库：账本内容、文件、AI 会话、账本级设置、提供商配置、API Key 均存入数据库；设备只保留界面与连接偏好。
- 存储服务只有两种：本地服务，或账本所在服务器。本地服务视为一台特殊服务器。
- 项目已上线，存在真实用户数据；修改数据结构、持久化格式或本地 store 形状时，兼容与迁移策略必须由用户最终拍板，禁止擅自假定无需兼容层或迁移。

## 存储位置决策

- 新增任何持久化数据（表、字段、本地 store、文件、凭据）前，必须由用户决定存储位置与作用域，禁止擅自决定。
- 提出选项时必须说明影响：
  - 账本切换行为：跨服务器、同服务器内切换时是否换源；
  - 跨设备：是否跟随账本/服务器在其他设备可见，是否需要重新配置；
  - 安全：是否进入服务器备份、导出和共享可见范围（尤其凭据）；
  - 可用性：离线、网络失败、延迟；
  - 迁移：是否需要迁移旧数据、旧数据如何处置。
- 决策必须回写到本文档的作用域表和切换影响表；未回写视为未定案，不得开始实现。
- 禁止隐式默认：不能因为本地实现现成就默认本地，也不能因为“统一”就默认入库；设备级与服务器级不得互相静默移动。
- 内存缓存、查询缓存、临时文件不属于持久化数据；一旦落盘或跨会话保留，即按本流程决策。

## 作用域

| 作用域   | 存储位置     | 隔离方式                 | 典型数据                                                                                                         |
| -------- | ------------ | ------------------------ | ---------------------------------------------------------------------------------------------------------------- |
| 账本级   | 账本所在服务 | `booksId`（业务表引用）  | 业务数据、图片文件、AI 会话、账本级设置、API Key                                                                 |
| 服务器级 | 账本所在服务 | 无 `booksId`，同服务共享 | 提供商配置、当前提供商与模型选择、跨账本数据                                                                     |
| 设备级   | 设备本地     | 不随账本或服务器         | 主题、提醒、快捷记账设置、自动备份设置与备份历史、自动检查更新设置、当前账本引用、服务器列表、网络服务器访问令牌 |

## 存储与切换影响

| 数据                                                                                              | 存储服务     | 跨服务器切换账本 | 同一服务器内切换账本 |
| ------------------------------------------------------------------------------------------------- | ------------ | ---------------- | -------------------- |
| 账本内容：业务数据、图片文件、AI 会话、账本级设置、API Key                                        | 账本所在服务 | 换源             | 只换账本             |
| 服务器级数据：提供商配置、当前提供商与模型选择、快捷记账模型选择；未来的成员/共享标签等跨账本数据 | 账本所在服务 | 换源             | 不变                 |
| 设备偏好与选择：主题、提醒、快捷记账设置、当前账本、服务器列表                                    | 设备本地     | 不变             | 不变                 |
| 网络服务器访问令牌（按 `serverUrl`）                                                              | 设备本地     | 不变             | 不变                 |
| 自动备份设置、备份历史与自动备份文件                                                              | 设备本地     | 不变             | 不变                 |
| 自动检查更新设置                                                                                  | 设备本地     | 不变             | 不变                 |
| 账本 AI 设置（提供商定义、模型选择与当前账本 API Key）                                            | 账本所在服务 | 换源；随账本导出 | 只换账本             |
| 设置包（快捷记账 + 主题）                                                                         | 设备本地     | 不变             | 不变                 |
| 网络账本列表（服务器地址、账本引用、访问令牌）                                                    | 设备本地     | 不变             | 不变；可导出与合并   |

## 归属规则

- 账本内容随书走：业务数据、文件、AI 会话、账本级设置和 API Key 都按 `booksId` 隔离；切换账本即切换数据源，跨服务器与同服务器内切换行为一致。
- 媒体文件在服务器使用平面目录 `<uuid>.<ext>`；文件归属由业务表引用（记录图片、封面、消息附件）决定，不按 `booksId` 分目录。当前接受孤儿文件，不做删除联动。
- 服务器级数据随服务器走：提供商配置、当前提供商与模型选择、快捷记账模型选择、未来的成员/共享标签等不带 `booksId`；同一服务器的多本书共享，跨服务器切换时换源。
- 服务器级数据只通过 API 读写，不在设备端持久化副本；provider、selection、快捷记账模型选择不进入本地 store。
- 设备级数据不动：主题、截图与提醒设置、快捷记账设置、自动备份设置与历史、自动检查更新设置、`lastHandledAssetId`、当前账本引用、服务器/网络账本列表、每服务器上次账本、网络服务器访问令牌只存本机；网络账本列表与令牌只在用户显式导出、导入或局域网传输时离开本机。
- 自动备份、手动导出与局域网传输共用同一套内容选择：按账本逐项勾选业务数据、图片、AI 会话与 AI 设置，并可附带设置包与网络账本列表。网络账本列表包与完整备份包含访问令牌；导入时合并服务器、令牌与账本引用，不删除本机已有项。
- 自动备份只处理本地账本内容；网络账本业务数据由所属服务器自行备份。备份文件默认存应用私有目录，用户可指定外部目录；目录权限与文件清理仅作用于本机。
- 账本 AI 设置随账本导出与导入：包含提供商定义、模型选择与当前账本 API Key；导入按 `descriptorId + baseUrl + name` 复用已有提供商，并把 Key 写入对应新账本；包内 Key 为空时保留目标已有 Key。
- 本地服务与网络服务器不共享数据：本地账本与服务器账本各自维护提供商配置和 API Key。
- 数据库只存媒体引用，不存设备绝对路径；本地账本为 `file://...`，由本地文件实现解析；网络账本为 `media:<uuid>.<ext>`，由所属服务器的 `GET /api/media/:fileName` 解析。
- 媒体上传使用 `multipart/form-data`，单文件上限 10MB，仅接受 `image/jpeg` / `image/png` / `image/webp`。
- 模型绑定与会话同存：仅在 thread 行记录 `providerId`/`modelId`；消息不单独记录模型；不再维护独立的设备级 thread model store。
- 账本列表是本地与各服务器 `book.getAll()` 的聚合视图，不单独持久化。

## 安全与边界

- API Key 暂按明文存入账本级凭据表。服务器备份、导出和共享成员均可读取；传输必须使用 HTTPS 或可信局域网。后续如需加密，需单独决策并实现服务端加密存储。
- 网络服务器访问令牌按明文存入设备本地 SQLite；不会自动上传服务器，但会进入用户显式生成的网络账本列表包与完整备份包，并可通过局域网传输；导出文件需妥善保管，换设备可通过列表包恢复。服务端启动必须设置至少 16 个字符的 `SERVER_TOKEN`；所有 `/api` 路由（含媒体上传与读取）统一校验 `Authorization: Bearer <token>`，未授权返回 401。
- 提供商 `baseUrl` 必须对所有设备可达；局域网/内网端点会出现“配置存在但设备不可用”。
- 服务器级选择在多设备间共享；未来引入多用户时需增加用户作用域。
- 删除提供商时必须处理 thread 引用：将引用 thread 的 `providerId`/`modelId` 置 `0`/`''` 并提示重新选择，不得留下悬空引用。
- 以下两类作用域变更会改变本表，必须显式拍板后同步更新：提供商配置改为账本级、API Key 改为服务器级。两者不得在实现中隐式混用。

## 实现落点

- `packages/data/src/schema`：服务器级提供商表、账本级凭据表、账本级设置/快捷模板、thread 的模型绑定字段（消息表不加模型字段）。
- `packages/data/src/services`：提供商、凭据、设置的唯一写入路径；写入必须走事务。
- `packages/data-server-wrapper`：新增提供商/设置 API group 与媒体上传、读取路由；启动读取 `SERVER_TOKEN`，全局中间件校验 Bearer 令牌。
- `src/stores`：仅保留设备级状态；账本级与服务器级设置改由 API 读写；provider 不设设备级 store 或运行时 registry；`networkBookStore` 设备级保存 `serverUrl -> token`。
