# 移除非必要测试用例

## 判断标准

一个测试用例应当被移除，当且仅当它命中以下黑名单中的任意一条。未命中任何条目的用例一律保留。

## 黑名单

### 1. TypeScript 类型约束测试

**识别方法**：用例代码中包含 `@ts-expect-error` 注释。这类用例验证的是编译期类型契约，不是运行时用户行为。

**处理**：移除命中用例。若整个文件均由此类用例组成，删除整个文件。

### 2. 注册表 / 源码结构测试

**识别方法**：用例测试的是组件内部数据结构（如预览注册表、组件映射表），而非组件渲染或交互行为。

**处理**：删除整个文件。

### 3. 动画生命周期测试

**识别方法**：用例验证的是动画引擎的内部机制，包括但不限于：

- `afterOpenChange` 回调的触发时机
- 组件在关闭动画期间保持挂载、动画结束后卸载的生命周期
- 进入 / 退出动画的状态转换细节

**判断依据**：用户只关心动画是否播放，不关心内部生命周期调度。若用例断言的是动画引擎的内部状态流转而非用户可见的动画效果，则命中。

**处理**：移除命中用例。

### 4. 定时器 / 延迟测试

**识别方法**：用例通过 `jest.advanceTimersByTime(...)` 推进时间来测试延迟行为（如 loading 延迟、自动消失）。

**排除**：仅使用 `jest.useFakeTimers().setSystemTime(...)` 固定当前日期作为测试前置条件的场景不命中（如日历组件需要固定"今天"的日期）。

**判断依据**：用例是否在断言时间驱动的状态变化。若是，则命中；若只是用 fake timer 控制环境，则不命中。

**处理**：移除命中用例。

### 5. 内部纯函数 / 工具函数测试

**识别方法**：用例从组件实现文件中导入内部工具函数并直接调用断言返回值，整个过程不涉及组件渲染。

**判断依据**：是否渲染了组件。若用例只调用函数、断言返回值而无任何 `render` / `create` 操作，则命中。

**处理**：移除命中用例。若移除后文件中无剩余用例，删除整个文件。

## 执行流程

1. 扫描 `packages/pennyspring-ui/__tests__/` 下所有测试文件
2. 逐文件解析 `it(...)` 块，按上述黑名单逐条判断
3. 命中的 `it(...)` 块用 Edit 工具移除
4. 移除后若 `describe(...)` 块为空，一并清理
5. 移除后若整个文件无剩余内容，删除文件
6. 运行 `yarn workspace @pennyspring/ui test` 验证剩余用例全部通过
7. 输出移除报告：列出每个文件移除了哪些用例及命中原因
