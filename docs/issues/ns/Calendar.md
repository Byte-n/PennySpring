# Calendar 自定义能力评估

## 现状

- 支持日期/月/年模式、格式化、禁用日期、标记、底部操作按钮文本/节点和基础样式插槽。
- 内部固定使用 `Icon`、`Text` 渲染头部翻页、网格单元和底部操作。

## 需要完善

- 日期单元缺少 `renderCell`/`renderDate`，无法按日期状态完整替换单元内容与交互区块。
- 头部只支持前后按钮节点，缺少 `renderHeader`，不能整体替换年月标题和导航结构。
- `marks` 仅支持按日期附加 content，缺少多标记、标记状态、标记渲染函数和范围选择单元自定义。
- 底部操作缺少 `footer`/`renderFooter`，无法替换今天、取消、确认按钮组合。
